This project is B2B market base a web system. In this project farmer can sell thiere product and customer can buy it,also supplier can sell thiere fertilizers, then farmer can purchase it. In other hand this system provide more option like image processing and many more analtical function. This system will enable farmers to sell their vegetables and fruits at a controlled price and also provide access to quality fertilizers and agrochemicals. Farmers can get detailed information about the nutrients of vegetables and fruits by uploading photos to the system. The system will also provide educational resources on different types of vegetables and fruits as well as new agricultural methods. Suppliers can register on the system and sell their agrochemicals.
